\# TECH6 term paper: replication of Meyersson (2014)



Group members: \[Daniel]



This repository replicates and extends statistical methods in Meyeresson (2014), "Islamic Rule and the Empowerment of the Poor and Pious. Tables I, II, III and VII and figures 1-4 from Meyersson (2014) were replicated in accordance to the authors original methods, and two extensions utilizing R and python were made.



\## How to run

1. Put "regdata0.dta" in the same folder as scripts
2. Open R in the folder and run "source("run\_all.R)
3. Python extension may take a mintue before finishing



\## Requirements

* R packages: haven, estimatr, ggplot2, gridExtra, rdrobust, rddensity, knitr
* Python packages: numpy, pandas, scikit-learn, matplotlib. Python must work with command 'python



Project was tested on Windows with R 4.5.2 and python 3.14
